## Our promise

Most apps today want your data, your attention and your internet connection. We build the opposite.

| | |
|---|---|
| 🚫 **No ads** | Not now, not ever. |
| 🕵️ **No tracking** | No analytics, no trackers, no third-party SDKs spying on you. |
| 📴 **Offline first** | Our apps work fully without an internet connection. |
| 🔒 **Your data stays yours** | Everything stays on your device. We never see it. |
| 🔓 **Open source** | Every line of code is public. Read it, audit it, learn from it. |
| 🆓 **Free** | No accounts, no subscriptions, no paywalls. |

## Get the apps

Our apps are distributed **only through GitHub**. There is no Play Store account and no middleman between you and the code.

1. Open the app's repository from the table above.
2. Go to **Releases** and download the latest signed `.apk`.
3. Install it on your Android phone.

Every release is built from the public source code in this organization, and the apps can check GitHub for updates themselves.

## Our principles

1. **Privacy is the default**, not a setting you have to find.
2. **The app should work without internet** whenever possible.
3. **Simple and focused**: each app does one job and does it well.
4. **Transparent**: open code, honest permissions, no hidden behavior.
5. **Built for everyone**: multi-language support and a clean, modern design.

## Contributing

Found a bug, have an idea or want to translate an app into your language? You're welcome here.

- 🐛 Open an **Issue** in the app's repository
- 💡 Suggest a feature in the repository's **Issues**
- 🌍 Send a **Pull Request** with a new translation or a fix

Please keep the spirit of the project in mind: **no ads, no trackers, no data collection.** Contributions that add any of these can't be accepted.
